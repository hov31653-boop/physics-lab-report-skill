# 1. 总原则与资料优先级

## 1.1 最高优先级原则

正式实验报告的：

- 一级标题；
- 二级标题；
- 标题名称；
- 标题层级；
- 章节顺序；
- 附录位置；
- 数据分析位置；
- 思考题位置；
- 实验小结位置；
- 参考文献位置；

必须严格按照 `实验报告要求/` 中**适用于当前实验的课程说明、教师模板和大章节要求**执行。

如果本总规则中的任何推荐结构与教师指定结构冲突：

> **无条件以教师最新、最具体、明确适用于当前实验的要求为准。**

本规则允许优化的是：

- 章节内部自然段顺序；
- 图表位置；
- 公式与文字衔接；
- 内容详略；
- 语言表达；

不得擅自：

- 新增正式一级或二级章节；
- 删除正式章节；
- 合并或拆分正式章节；
- 改写正式章节名称；
- 改变正式章节顺序；
- 把附录改成正文；
- 把正文改成附录；
- 把数据分析移到错误章节。

---

## 1.2 资料分工与冲突处理

不再把所有资料简单排成一条统一优先级。不同事项由不同资料主导。

总原则：

> **教师最新、最具体、明确适用于当前实验的要求具有最高优先级。**

按事项分工：

| 事项 | 优先依据 |
|---|---|
| 实验做什么、测什么、怎么做 | 当前实验讲义 / 当前大章统一要求 |
| 正式报告标题、层级、顺序、附录位置 | 教师正式模板 / 教师明确结构要求 |
| 哪些实验必做、选做、合并提交 | 大章节要求 / 课程说明 |
| A/B 类不确定度、传播、有效数字 | 课程指定不确定度资料 |
| 仪器型号、精度、误差限 | 课程资料；不足时再用厂家官方资料 |
| 通用物理解释 | 在不与课程资料冲突时使用通用物理知识 |

发生冲突时：

```text
先判断冲突属于哪一事项
→ 找该事项的主导资料
→ 再看教师是否有更新、更具体的明确要求
→ 若仍无法唯一判断，则向用户说明冲突并等待确认
```

不得只看实验标题、目录、第一页或某个截图就开始写报告。

---

## 1.3 数据真实性

必须区分：

| 类型 | 处理 |
|---|---|
| 用户真实实测值 | 实验前留空；实验后只读分析 |
| 讲义给定值 | 可预填，注明来源 |
| 计划设定值 | 可预填，明确标为设定值 |
| 理论值 / 参考值 | 标明来源，只用于比较或计算 |
| 自动计算值 | 放在公式区或结果文件 |
| 现象、异常、操作问题 | 只能来自用户真实记录 |

严格禁止：

- 编造实验数据；
- 为接近理论值而改数；
- 为提高拟合优度而静默删点；
- 把模拟数据当成实测数据；
- 把计划设定值冒充实测值；
- 把常见实验现象当成本次真实现象。

原始 Excel、原始照片、仪器导出文件和扫描记录均视为原始证据，不得覆盖或删除。

---

## 1.4 公共资料保护

以下内容默认只读：

```text
实验报告要求/
个人信息.txt
用户填入真实数据后的原始 Excel
```

不得在 `实验报告要求/` 中：

- 编译 LaTeX；
- 保存截图；
- 写缓存；
- 建立当前实验成果目录；
- 删除或覆盖母模板。

所有处理、截图、裁剪、程序、测试文件均放入当前大章节目录。


## 2.2 个人信息

统一从根目录 `个人信息.txt` 读取。

推荐格式：

```text
姓名：{{姓名}}
```

不得：

- 从其他用户资料中补全；
- 从历史对话猜测；
- 使用模板示例姓名或学号；
- 丢失学号前导零。

缺失时保留明确占位或询问用户，不得伪造。

## 2.4 内部文件名与最终提交文件名

### 内部管理文件

使用：

```text
流程编号 + 文件功能 + 实验正式名称
```

例如：

```text
03_实验数据填写表_利用单摆测重力加速度.xlsx
04_数据处理程序_利用单摆测重力加速度.py
```

### 最终报告类文件

正式提交的主报告文件名统一采用：

```text
姓名+学号+实验内容
```

例如：

```text
{{姓名}}{{学号}}{{实验正式名称}}.pdf
{{姓名}}{{学号}}{{实验正式名称}}.tex
```

其中“实验内容”优先使用讲义正式实验名称。

若同一实验存在多个必须独立提交且扩展名相同的报告类文件，为避免重名，可在主名称后添加**必要且明确的功能词**：

```text
姓名+学号+实验内容+预习报告.pdf
姓名+学号+实验内容+数据处理.pdf
姓名+学号+实验内容+附录.pdf
```

正式主实验报告仍优先使用：

```text
姓名+学号+实验内容.pdf
```

禁止使用：

```text
最终版
最新版
new
final
v2
v3
```

等无意义版本词。

# 3. 章节识别、资料提取与任务判定

## 3.1 第一件事：先识别“大章节”

收到“开始某实验 / 某章”后，不直接零散查当前实验。

必须先定位：

- 大章节正式编号；
- 大章节正式名称；
- 起始页；
- 结束页；
- 章节统一要求页；
- 本章包含的全部实验；
- 各实验正式编号和名称。

---

## 3.2 提取 / 整理本章实验资料

从课程提供的 PDF / PPTX / DOCX 等资料中提取或整理：

- 大章节首页 / 开始位置；
- 章节统一要求；
- 本章各实验正文；
- 本章末尾数据处理要求；
- 思考题；
- 分散在前后页的补充说明。

必要时可统一整理或导出为：

```text
第XX章_[大章名称]/
└─ 00_章节资料/
   └─ 00_讲义节选_[大章名称].pdf
```

原课程资料始终只读，不修改。

---

## 3.3 先读统一要求，再读单个实验

重点识别：

- 哪些实验必做；
- 哪些实验选做；
- 哪些实验写完整报告；
- 哪些实验只做数据处理；
- 哪些实验作为其他报告的附录；
- 哪些实验不写正式报告；
- 哪些实验需要合并提交；
- 主报告与附录关系；
- 本章统一的不确定度要求；
- 本章统一的作图要求；
- 本章正式报告结构。

---

## 3.4 本章实验任务判定表

在 `00_章节状态_[大章名称].md` 中建立唯一标准任务表：

| 实验编号 | 实验名称 | 完成要求 | 课程是否要求提交预习（仅记录，不影响生成） | 正式报告类型 | 归属主报告 / 附录 | 主要数据任务 | 主要分析任务 | 判断依据 | 当前状态 |
|---|---|---|---|---|---|---|---|---|---|

说明：

- `完成要求`：必做 / 已选做 / 未选；
- 只要 `完成要求` 为“必做”或“已选做”，第一步自动生成预习报告和数据表；
- 不再单独设置“是否需要数据表”字段，避免与第一步硬规则冲突；
- `正式报告类型`：完整报告 / 数据处理 / 附录 / 无正式报告；
- `判断依据` 必须写明文件 + 页码 / 章节；
- `当前状态`：未开始 / 已准备 / 等待数据 / 待补录 / 待重测 / 可分析 / 已完成。

无法可靠判断时写：

```text
状态：待确认
原因：
影响：
```

不得自行猜测。

# 4. 第零步与四步工作流总览

整个流程统一为：

```text
第零步：指定大章 → 读取信息 → 提取并理解本章 → 确认自定义设置
第一步：实验前准备
第二步：真实数据检查
第三步：正式数据分析与大纲
第四步：正式报告生成与交付
```

---

## 第零步：开始一个实验大章并确认设置

### 0.1 触发方式

当用户发送类似：

```text
根据总规则，开始[实验大章名称]
根据总规则开始“{{大章名称}}”
读取总规则并开始{{大章名称}}
开始{{大章名称}}，按总规则执行
```

并且明确给出实验大章名称时，执行完整第零步。

仅发送“读取总规则”而**没有指定实验大章**时，只读取规则并说明尚需实验大章名称，不创建章节状态文件，也不进入完整第零步。

### 0.2 先识别并理解指定大章

收到大章名称后，先完成：

```text
读取个人信息.txt
→ 读取实验报告要求/
→ 定位指定实验大章
→ 识别大章编号、名称和范围
→ 提取 / 整理该章课程资料
→ 阅读统一要求
→ 阅读本章全部实验内容
→ 识别报告类型、测量任务、分析任务、仪器需求
→ 建立初步任务判定
```

这一步的目标是：

> **先理解本章，再向用户推荐和展示适合本章的自定义设置。**

必要时将该章 PDF / PPTX / DOCX 内容整理为：

```text
第XX章_[大章名称]/
└─ 00_章节资料/
   └─ 00_讲义节选_[大章名称].pdf
```

原课程资料保持只读。

### 0.3 基于本章给出“检查数据”推荐阈值

“检查数据”的筛查阈值属于**用户自定义设置**，不再固定为某个统一百分比。

第零步应根据当前实验给出一个推荐值，并说明依据。

筛查阈值采用“两阶段推荐”：

### 第一阶段：第零步先按该实验的一般现实情况给出初始推荐

即使仪器精度尚未完全确认，也要结合当前实验类型给出一个**现实可用的初始推荐阈值**。

推荐时优先参考：

1. 课程 / 教师是否给出允许相对误差、目标精度或类似要求；
2. 理论 / 参考值是否可靠；
3. 本实验在普通本科实验室中的典型可达精度；
4. 实验属于高精度测量、普通定量测量还是规律 / 现象验证；
5. 实验模型是否存在明显近似；
6. 主要测量步骤是否容易受人工操作、环境或拟合过程影响；
7. 当前数据处理方法（直接测量 / 拟合 / 间接量）对偏差的敏感程度。

这一阶段的阈值标记为：

```text
筛查阈值状态：初始推荐
```

### 第二阶段：仪器精度明确后给出更具体的推荐

当第二步或第 13 节已经明确主要仪器的：

- 分辨率；
- 分度值；
- 准确度；
- 最大允许误差；
- 准确度等级；
- 其他关键精度参数；

则重新评估当前实验的筛查阈值。

此时应结合：

```text
仪器精度
+
预计传播影响
+
重复测量波动
+
实验模型近似
+
课程目标
```

给出更具体的推荐值。

如果新推荐值与第零步初始值基本一致：

```text
保留原阈值
→ 在状态文件中标记“已由仪器参数复核”
```

如果差异明显：

```text
给出新推荐值
→ 说明变化原因
→ 等待用户确认是否更新
→ 更新章节状态文件
```

不得在用户未确认时静默修改已经确认的筛查阈值。

推荐输出格式：

```text
检查数据筛查阈值（初始推荐）：{{值}}
推荐依据：
- ...
- ...

仪器精度明确后：
→ 将再次复核并给出更具体的推荐值。

说明：该阈值只用于内部快速筛查，不是正式统计检验或计量学判据。
```

不得把推荐阈值写入正式实验报告。

### 0.4 输出当前已读取信息和自定义设置

完成本章理解后，向用户输出：

```text
【第零步：本章信息与设置确认】

大章：
章节编号：
本章包含实验：
本章统一要求摘要：
预计报告类型：

姓名：
班级：
学号：
学校 / 学院（如有）：
课程名称（如有）：

Excel 配色方案：
- 原始输入：
- 固定 / 参考参数：
- 现场初步计算：
- 关键提醒：

Excel 表格边框：
正式报告数据表格类型：
正式报告原始数据放置方式：

检查数据筛查阈值（初始推荐）：
筛查阈值状态：初始推荐 / 已由仪器参数复核
推荐依据：

其他已读取个性化设置：

请确认以上信息，或直接告诉我需要修改的项目。
```

默认表现层设置：

```text
Excel 配色：当前规则默认配色
Excel 工作表表格：全框
正式报告数据表格：全框表格
正式报告原始数据：放入附录
正文数据内容：拟合相关参数、最终结果及必要分析
```

正式报告数据表格可改为三线表；Excel 颜色也可由用户自定义。

### 0.5 等待用户确认

第零步输出后必须等待用户确认或修改。

用户可以回复：

```text
确认
按推荐设置
按默认
```

也可以修改：

```text
正式报告改为三线表
原始输入改成浅绿色
检查数据阈值改为 2.5%
```

用户确认前，不得进入第一步生成预习报告、正式数据表或其他实验成果。

### 0.6 用户确认后生成并输出本章状态文件

第零步前半段只负责：

```text
读取信息
→ 提取 / 整理并理解本章
```

# 5. 第一步：实验前准备

## 5.1 所有实际要做的实验都必须生成预习报告

这是硬性规则。

无论该实验最终属于：

- 完整正式报告；
- 只做数据处理；
- 附录型实验；
- 不要求正式报告；

只要用户实际准备做该实验，第一步都生成：

```text
01_预习报告_[实验名称].tex
02_预习报告_[实验名称].pdf
03_实验数据填写表_[实验名称].xlsx
```

“课程是否明确要求提交预习”只作为状态记录字段，不决定是否生成预习。

---

## 5.2 预习报告内容

优先依据讲义组织：

- 实验目的；
- 实验原理；
- 主要公式；
- 仪器与器材；
- 实验内容；
- 关键操作；
- 测量方案；
- 记录要求；
- 讲义思考题或预习问题。

课程有预习模板时严格按模板。

无明确页数要求时，默认尽量控制在约 2 页，但**不能通过删除必要物理解释、过度缩小字号或挤压排版强行压页数**。

---

## 5.3 从最终结果反推测量方案

设计数据表前先回答：

```text
最终要得到什么物理量？
↓
需要哪些公式 / 拟合 / 图像？
↓
这些结果依赖哪些直接测量量？
↓
每个直接量需要怎样的不确定度？
↓
哪些原始读数必须保留？
↓
需要多少次重复、多少个自变量点、哪些环境条件？
```

对每个关键量明确：

- 单位；
- 记录精度；
- 重复次数；
- 是否需要 A 类评定；
- 已知仪器分辨率或精度；
- 是否进入最终误差传播；
- 是否可能成为主导不确定度来源。

---

## 5.4 拟合类实验的实验前设计

拟合实验应提前考虑：

- x 轴范围是否足够；
- 点数是否足够；
- 是否需要重复测量；
- 是否记录实际 x 而非只记录名义设定值；
- 是否需要零点 / 背景；
- 是否需要误差棒；
- 是否需要残差图；
- 是否需要理论线或参考线。

不要在实验结束后才发现缺少拟合所需信息。

---

## 5.5 第一阶段完成条件

第一步结束前确认：

- 本章讲义节选已生成；
- 本章统一要求已识别；
- 各实验报告类型已判断；
- 所有实际要做的实验都已生成预习 `.tex/.pdf`；
- 所有实际要做的实验都已生成数据填写表；
- 需要正式报告的实验已锁定正式报告结构；
- 章节状态文件已更新；
- 预习 PDF 已实际编译并检查；
- 实验数据表可直接用于现场记录。

完成后停止，等待真实实验。

# 6. Excel 数据表、现场计算与测量规划

## 6.1 第一张工作表固定为“测量注意事项”

第一张工作表必须命名：

```text
测量注意事项
```

记录当前实验真正需要注意的内容：

- 哪些数据最关键；
- 单位；
- 记录精度；
- 重复次数；
- 如何测量；
- 容易犯的错误；
- 漏测后会影响什么；
- 哪些量对最终结果最敏感。

不要写泛泛的“认真读数”“规范操作”。

---

## 6.2 后续工作表

按讲义任务和物理意义命名，例如：

```text
固定摆长测量
变摆长测量
温度变化测量
伏安特性
现场初步结果
```

不要使用：

```text
Sheet1
Data
Raw
Task1
```

等模糊名称。

---

## 6.3 原始数据结构

原则：

- 一行一个观测；
- 一列一个物理量；
- 单位写在表头；
- 数值格保持数值类型；
- 实测输入格实验前保持真正空白；
- 计划值、讲义值与实测值分开；
- 不用合并单元格承载数据；
- A 类分析所需的每次重复测量必须全部保留；
- 不只保留平均值。

---

## 6.4 Excel 视觉语义

默认采用以下配色；如果第零步中用户已经确认其他个性化颜色，则以章节状态文件中的确认值为准。

| 含义 | 默认样式 |
|---|---|
| 用户原始输入 | 淡黄色 `#FFF2CC` |
| 固定 / 讲义给定 / 参考参数 | 浅灰 `#E7E6E6` |
| 现场初步计算 | 淡蓝 `#DDEBF7` |
| 关键警告 | 少量红色文字或边框 |

其他要求：

- 主表外框清楚；
- 表头有明确边框；
- 内部边框细；
- 列宽合理；
- 自动换行；
- 冻结必要表头；
- 显示位数与仪器记录精度一致；
- 不做花哨仪表盘；
- 不做 3D 图；
- 不用大量颜色装饰。

---

## 6.5 现场初步计算

Excel 可提供“现场初步结果”，用于判断是否需要当场补测。

可以包含：

- 平均值；
- 标准差；
- 极差；
- 简单导出量；
- 简单线性趋势；
- `SLOPE`、`INTERCEPT`、`RSQ`；
- 现场相对偏差；
- 简单 A 类不确定度；
- 课程方法明确时的 B 类分量；
- 初步合成不确定度；
- 必要的散点图或趋势图。

必须标明：

```text
现场初步结果，正式值以后续 Python 正式分析为准。
```

公式必须处理空白数据，避免 `#DIV/0!` 等错误。

---

## 6.6 现场公式的作用边界

Excel 现场公式只用于：

- 判断是否漏测；
- 判断重复性是否太差；
- 判断趋势是否明显异常；
- 判断是否需要补测。

正式报告中的最终数值必须由第三步重新读取原始数据并独立计算。

<a id="sec-07"></a>
# 7. 第二步：真实数据检查

第二步只负责**检查数据是否具备进入正式分析的条件**。

第二步不生成最终正式报告，不完成正式排版，不执行最终交付。

---

## 7.1 读取范围

读取：

- 章节状态文件；
- 当前实验讲义；
- 本章统一要求；
- 用户填写后的原始 Excel；
- 相关原始照片或仪器导出文件；
- 已知仪器参数。

---

## 7.2 完整性检查

检查：

- 必做数据是否全部填写；
- 重复次数是否满足要求；
- 自变量点数、范围、步长是否满足要求；
- 单位是否正确；
- 记录精度是否足够；
- 零点、背景、环境条件是否缺失；
- 设定值与实测值是否混淆；
- 是否缺少进入最终传播的直接量；
- 是否缺少拟合所需点；
- 是否缺少课程要求的日期、条件或现场记录；
- **讲义、课程资料或原始记录中是否已经给出当前实验仪器的量程、分度值、分辨率、准确度、最大允许误差、准确度等级、零点修正、标定修正等参数；**
- **这些仪器参数是否足以完成后续 B 类不确定度、误差传播和“检查数据”中的仪器影响判断。**

仪器参数检查必须逐台、逐项完成。至少记录：

| 仪器 | 型号 / 标识 | 量程 | 分度值 / 分辨率 | 准确度 / 最大允许误差 | 零点 / 标定修正 | 资料来源 | 当前状态 |
|---|---|---:|---:|---:|---:|---|---|
| {{仪器}} | {{型号}} | {{值}} | {{值}} | {{值}} | {{值}} | {{讲义/说明书/待查}} | 已知 / 缺失 / 待确认 |

如果仪器参数缺失，第二步只负责登记缺失并明确告诉用户：

```text
缺少哪一台仪器的哪个参数
→ 该参数会影响什么计算
→ 是否会影响后续“检查数据”或第三步正式分析
```

不得静默跳过。

缺失时明确输出：

| 缺项 | 工作表 / 位置 | 为什么需要 | 后续处理 |
|---|---|---|---|
| ... | ... | ... | 按第13节处理 |

第二步不在此重复执行联网搜索，也不提前做第三步正式不确定度分析。

---

## 7.3 物理合理性检查

检查：

- 数量级；
- 正负号；
- 单位换算；
- 小数点；
- 是否超仪器量程；
- 记录位数是否超过仪器能力；
- 重复测量是否明显离散；
- 数据是否出现突变；
- 理论上应单调 / 线性 / 成比例的关系是否严重破坏；
- 中间量是否落入明显不合理范围；
- 是否存在可疑录入错误。

---

## 7.4 异常点原则

异常 ≠ 自动错误。

不得仅因为：

- 离理论值远；
- 降低 `R²`；
- 某个点不“漂亮”；

就删除数据。

发现可疑点时：

```text
定位原始记录
→ 检查单位、录入、小数点
→ 检查相邻点和重复测量
→ 检查残差 / 趋势
→ 检查是否有真实操作异常记录
→ 决定是否建议重测
```

只有有明确依据时才建议排除；否则保留并在第三步正式分析中讨论。

---

## 7.5 第二步判定分级

### A. 正常

数据完整，物理关系基本合理，可进入后续。

### B. 可疑但可用

存在偏离，但没有明确错误证据；保留数据，第三步重点分析。

### C. 需要补录

缺失内容可从用户已有原始记录补入。

### D. 建议重测

存在明显录入错误、数量级错误、操作异常、关键数据缺失或无法满足课程分析要求。

若需重测，停止依赖该数据的后续工作，等待用户更新原始 Excel。

# 8. 用户触发“检查数据”确认门

该步骤位于第二步之后、第三步之前。

**只有用户明确发送：**

```text
检查数据
```

才启用。

如果用户没有触发，不自动执行这一额外确认门。

一旦触发，无论结果如何，都必须等待用户明确确认后才能进入第三步。

---

## 8.1 快速计算

触发后只做简化计算，快速得到：

- 主要实验结果；
- 关键平均值；
- 必要的简单拟合；
- 主要参考量；
- 实验值与理论值 / 参考值的差异。

这不替代第三步正式不确定度与完整分析。

---

## 8.1.1 调用第二步仪器参数核对结果

“检查数据”不再重复做一遍仪器清单检查。

直接读取第二步已经记录的仪器参数状态：

```text
参数齐全
→ 继续检查

存在缺失
→ 按第13节联网补全流程处理
```

未经用户对联网的明确授权，不自行联网。


---

## 8.2 先处理仪器影响

仪器影响分两类。

### 可明确校正的系统修正

例如：

- 已知零点修正；
- 已知标定修正；
- 已知确定性刻度修正。

可先得到：

```text
Q_corr = Q_exp + C_instr
```

其中 `C_instr` 明确定义为**已知修正值**；若资料给的是“示值偏差”，必须先按定义换算成修正值，避免符号混乱。

### 不能直接校正的仪器不确定度

例如：

- 分辨率；
- 最大允许误差；
- 准确度等级；
- 未知方向的读数限。

不能简单从结果中“减掉”。

应通过一阶传播或课程规定方法得到仪器对最终结果的可解释范围：

```text
U_instr
```

---

## 8.3 使用第零步已确认的筛查阈值

有可靠理论值 / 参考值时，使用章节状态文件中已经确认的：

```text
δ_threshold
```

作为内部快速筛查阈值。

定义快速筛查剩余偏差：

```text
δ_screen
=
max(0, |Q_corr - Q_ref| - U_instr)
/
|Q_ref|
× 100%
```

其中：

- `Q_corr`：经过明确系统修正后的实验值；
- `Q_ref`：可靠理论值 / 参考值；
- `U_instr`：检查阶段可获得的仪器影响估计；
- `δ_threshold`：第零步针对当前实验推荐并经用户确认的内部筛查阈值。

判据：

```text
δ_screen ≤ δ_threshold
→ 快速检查视为正常

δ_screen > δ_threshold
→ 重点复查偏差来源和可能重测点
```

注意：

> `δ_screen` 与 `δ_threshold` 都只用于本项目内部的启发式快速筛查，不是正式统计检验或计量学判据，也不替代第三步正式不确定度分析。

正式报告中不得出现内部筛查阈值、“通过 / 未通过筛查”或用户确认门，除非课程明确要求披露内部检查方法。

正式报告只保留实验本身有意义的结果，例如：

```text
实验值
理论值 / 参考值
实际相对偏差
不确定度
主要误差来源
物理解释
```

---

## 8.4 没有可靠理论值时

若当前实验没有可靠理论值 / 参考值，则：

- 不使用数值筛查阈值；
- 不凭空设参考值；
- 改用：
  - 重复性；
  - 标准差；
  - 残差；
  - 单调性；
  - 线性关系；
  - 内部一致性；
  - 物理范围；
  - 相邻点趋势；
  - 仪器量程；

进行快速检查。

仍必须等待用户确认。

---

## 8.5 超过本章已确认筛查阈值时

优先定位：

- 对最终结果最敏感的直接量；
- 不确定度贡献最大的量；
- 残差最大的数据点；
- 重复性最差的数据组；
- 与相邻趋势差异最大的点；
- 可能有单位 / 小数点 / 录入错误的数据；
- 可能存在基准位置或零点问题的量。

输出应尽量具体：

```text
第4组累计计时明显高于相邻摆长趋势，
且该点残差最大，建议优先重测第4组。
```

不要只写：

```text
可能有人为误差。
```

## 9.2 追加数据统一分析

如果用户后来补充或追加实验数据，且属于：

- 同一测量条件；
- 同一物理任务；
- 同一拟合关系；
- 同一最终结果；

则：

> **直接并入原有数据集统一分析，不另做一套“追加数据分析”。**

重新计算受到影响的：

- 均值；
- 标准差；
- 不确定度；
- 拟合；
- 残差；
- 图表；
- 最终结果。

---

## 9.3 区分概念

### 误差

有合适参考值时，可讨论实验值与参考值之差。

### 偏差 / 离差 / 残差

用于描述：

- 数据点相对平均值；
- 数据点相对拟合值；
- 多次测量之间的差异。

### 不确定度

描述测量结果的可信范围 / 分散程度。

### 离散性

通过：

- 标准差；
- 极差；
- 相对标准差；
- 标准误；

等量描述。

不要把所有概念都称为“误差”。

---

## 9.4 A 类与 B 类不确定度

严格按照课程指定资料。

### A 类

基于重复测量统计。

必须保留所有重复测量原始值。

### B 类

基于课程明确给出的：

- 仪器分辨率；
- 准确度；
- 误差限；
- 准确度等级；
- 标定参数；
- 官方规格。

课程未明确分布类型时，不擅自套统一分布模型。

---

## 9.5 间接量传播

对于：

```text
Q = Q(x1, x2, ..., xn)
```

按课程规定的不确定度传播公式执行。

课程允许一阶独立传播时，可使用：

```text
u_c(Q)^2
=
Σ [ (∂Q/∂xi) u(xi) ]^2
```

若量之间有关联，不得默认独立。

---

## 9.6 不确定度贡献

数据允许时计算：

```text
ci = ∂Q/∂xi
ui(Q) = |ci| u(xi)
```

课程允许时可计算贡献比例：

```text
Pi = ui(Q)^2 / uc(Q)^2 × 100%
```

正文需要解释：

- 哪个量贡献最大；
- 为什么；
- 哪个测量步骤最值得改进。

---

## 9.7 误差分析：先分“误差类型”，再找“误差来源”

正式分析时必须区分：

```text
误差类型
≠
误差来源
```

“随机误差、系统误差、粗大误差 / 异常失误”描述的是误差在数据中的**性质和表现方式**；

“仪器、操作、环境、方法、模型”等描述的是误差可能来自哪里。

不要把：

```text
仪器误差
人为误差
环境误差
方法误差
```

直接当成与“随机误差、系统误差”并列的同一级分类。

### 9.7.1 随机误差

随机误差通常表现为：

- 多次重复测量在平均值附近上下波动；
- 偏差方向不固定；
- 重复测量存在离散；
- 拟合残差在零附近无明显规律地正负变化；
- 增加重复测量通常可以改善均值的统计稳定性。

可优先通过以下量分析：

- 标准差；
- 极差；
- 相对标准差；
- A 类不确定度；
- 均值标准不确定度；
- 拟合残差的随机散布。

典型可能来源包括：

- 读数末位波动；
- 手动计时反应差异；
- 环境微小随机扰动；
- 仪器短期随机噪声；
- 重复定位的不完全一致。

随机误差的正式讨论应尽量回答：

```text
随机波动有多大？
↓
是否明显影响最终结果？
↓
哪个直接测量量的随机波动最重要？
↓
增加重复次数或改善操作能否有效降低影响？
```

### 9.7.2 系统误差

系统误差通常表现为：

- 多组结果整体偏高或整体偏低；
- 偏差方向较稳定；
- 残差随自变量呈持续趋势；
- 正反程、不同仪器或不同方法之间存在稳定差异；
- 增加重复次数并不能消除该偏差。

常见可能来源包括：

- 仪器零点偏移；
- 标定误差；
- 固定基准位置判断偏差；
- 仪器准确度限制；
- 理论模型近似造成的固定方向影响；
- 忽略某个稳定修正项；
- 长期环境条件造成的整体偏移；
- 测量方法本身引入的方向性偏差。

系统误差的正式讨论应尽量回答：

```text
偏差是否具有一致方向或趋势？
↓
哪个物理量最可能产生这种偏移？
↓
该偏移怎样传播到最终结果？
↓
能否校正、标定或改进实验方法？
```

系统误差只有在存在数据趋势、装置机制或明确物理依据时才可以判断。

不得仅因为：

```text
实验值与理论值有偏差
```

就直接断言“存在系统误差”。

### 9.7.3 粗大误差 / 异常失误

粗大误差通常来自：

- 录入错误；
- 单位错误；
- 小数点错误；
- 明显读错刻度；
- 操作步骤失误；
- 仪器档位使用错误；
- 瞬时故障；
- 漏记或错记数据。

它往往表现为：

- 单个点远离其他数据；
- 单点残差异常大；
- 与相邻趋势严重不一致；
- 超出合理物理范围；
- 与原始记录中的操作异常相对应。

粗大误差属于数据质量问题，不能简单当作“随机误差较大”。

处理顺序必须是：

```text
发现异常
→ 回查原始记录
→ 检查单位、录入和操作
→ 查找明确证据
→ 再决定重测、保留或排除
```

没有明确依据时，不自动删除异常点。

### 9.7.4 误差来源的机制分类

在确定“随机 / 系统 / 粗大”性质后，再追查具体来源。

可从以下机制中选择：

- 仪器分辨率与读数限制；
- 仪器零点或基准偏移；
- 仪器标定与准确度限制；
- 读数与操作过程；
- 几何位置与参考位置确定；
- 环境条件；
- 理论模型近似；
- 数据处理方法；
- 短期随机噪声；
- 其他有明确物理依据的因素。

同一个来源可能对应不同误差类型。

例如：

```text
手动计时反应差异
→ 主要表现为随机误差

秒表存在固定零点偏差
→ 主要表现为系统误差

某次按键提前一整秒
→ 更接近粗大失误
```

因此正式报告不能只写“人为误差”或“仪器误差”，而应继续说明它属于什么性质、如何影响数据。

### 9.7.5 不确定度与误差类型必须区分

不确定度用于量化测量结果的可信范围，不等于“已经知道的真实误差”。

因此：

```text
A 类不确定度
通常用于描述重复测量中的统计波动

B 类不确定度
通常用于描述仪器、校准、分辨率等非统计信息带来的不确定性
```

但：

```text
A 类 ≠ 随机误差本身
B 类 ≠ 系统误差本身
```

例如一个固定零点偏移属于系统性影响；若未进行校正，可以通过相关参数评估其不确定性，但不能因此把“B 类不确定度”和“系统误差”当作同义词。

---

## 9.7.6 正式报告只重点分析 1～2 个主要误差类型

面对多个可能误差时，**不要求把所有类别平均展开**。

正式报告应优先选择对当前实验最重要的 **1～2 个误差类型或误差机制** 进行重点分析。

选择优先级：

1. 对最终结果贡献最大；
2. 在不确定度贡献中占比明显；
3. 在重复测量、残差或图像中有明显表现；
4. 对最终结果灵敏度高；
5. 能解释实验值与理论 / 参考值之间的主要偏差；
6. 有真实实验记录或装置机制作为依据；
7. 对改进实验方案最有意义。

例如：

```text
主要问题是重复计时波动
→ 重点分析随机误差

结果整体偏高，且长度测量基准可能存在固定偏移
→ 重点分析系统误差

同时存在较明显随机波动和整体偏移
→ 重点分析“随机误差 + 系统误差”两类
```

次要误差可以在一段中简要说明，不需要每一种误差都独立成节或配图。

---

## 9.7.7 每个主要误差必须形成完整分析链

对于选中的 1～2 个主要误差，尽量按以下链条分析：

```text
误差类型
→ 具体来源
→ 影响的直接测量量
→ 数据中的证据
→ 传播到最终结果的机制
→ 影响大小或方向
→ 对应图像 / 表格
→ 改进方法
```

例如：

```text
随机误差
→ 手动计时反应差异
→ 影响累计计时 t
→ 多次重复计时存在明显离散
→ T=t/N，进而传播至最终 g
→ A 类不确定度表明时间项贡献为……
→ 配合“重复测量散点图 / 箱线图”
→ 增加累计周期数并规范起止时刻判断
```

或者：

```text
系统误差
→ 有效长度基准位置判断偏大
→ 影响 L
→ 多组结果整体偏向同一侧
→ g 与 L 呈确定传播关系
→ 对最终结果产生同方向偏移
→ 配合“实验值-参考值对比图 / 残差趋势图”
→ 改进基准位置确定和长度标定
```

## 9.8 拟合与残差

拟合必须说明：

- 拟合模型；
- x、y 物理量；
- 是否需要截距；
- 是否强制过原点；
- 参数物理意义；
- `R²` 的含义；
- 残差行为；
- 是否有异常点；
- 参数标准误差与完整不确定度的区别。

不得把高 `R²` 直接等同于“结果准确”。

---

## 9.9 第三步结束前生成“总体文字大纲”

在最终数值、图表和分析确定后，必须先生成正式报告总体文字大纲，再进入第四步。

大纲严格映射教师正式结构。

每个自然段至少记录：

| 项目 | 内容 |
|---|---|
| 所属正式章节 | 教师模板原始标题 |
| 段落主题 | 本段解决什么问题 |
| 主要内容 | 要写什么 |
| 关键证据 | 公式 / 表 / 图 / 数据 |
| 段落作用 | 引入 / 解释 / 比较 / 讨论 / 总结 |
| 与上一段关系 | 如何承接 |
| 与下一段关系 | 引向什么 |
| 图表安排 | 对应哪张图 / 表 |
| 数据放置 | 原始数据默认进入附录；正文仅安排拟合参数 / 最终结果 |
| 不确定度 / 误差 | 是否涉及 |
| 真实实验记录 | 是否有可写现象或问题 |

大纲只规划内容，不进入最终 PDF。

# 10. 统计表与图表表达

## 10.0 正式报告数据表格样式

正式报告中的数据表格样式由第零步确认。

可选：

```text
全框表格
三线表
```

默认：

```text
全框表格
```

### 全框表格

- 横线、竖线完整；
- 适合教学实验报告；
- 多列数据时便于逐格核对。

### 三线表

- 一般保留顶线、表头下横线、底线；
- 默认不使用竖线；
- 适合教师偏好论文式表格的课程。

优先级：

```text
教师 / 课程明确要求
>
章节状态文件中用户确认的个性化设置
>
本规则默认全框表格
```

无论选择哪一种，都必须保持表头、单位、数值对齐、有效数字和表题清楚。

---

## 10.0.1 原始数据默认放入附录

正式报告默认采用：

```text
正文
→ 不放完整原始数据表
→ 只保留拟合相关参数、最终结果、必要图像与分析

附录
→ 放置完整原始数据
→ 保留可追溯的测量记录
```

### 正文应优先保留

对于拟合类实验，正文中的数据内容主要保留：

- 拟合模型；
- 斜率；
- 截距；
- 拟合参数的不确定度 / 标准误（课程允许时）；
- `R²` 或课程要求的拟合优度指标；
- 关键残差特征；
- 由拟合参数得到的最终物理量；
- 最终结果及不确定度；
- 必要的拟合图、残差图；
- 对拟合参数物理意义的解释。

正文可以使用简洁的“拟合参数表”，例如：

| 参数 | 数值 | 不确定度 / 标准误 | 单位 | 物理意义 |
|---|---:|---:|---|---|
| 斜率 | ... | ... | ... | ... |
| 截距 | ... | ... | ... | ... |
| `R²` | ... | — | — | 拟合优度 |

### 附录应保留

附录中放置：

- 完整原始测量数据表；
- 多次重复测量的逐次读数；
- 各自变量点的原始记录；
- 必要的仪器原始导出数据；
- 课程要求保留的原始数据处理依据。

如果原始数据量较大，可以按实验任务分表，但不能删去影响复算的关键原始读数。

### 不重复堆表

同一套原始数据已经完整放在附录后，正文原则上不再重复复制整张原始数据表。

正文如确需引用，只提取：

- 拟合参数；
- 最终结果；
- 关键比较量；
- 极少量用于说明异常或趋势的代表性数据。

### 教师要求优先

如果教师模板或课程明确要求：

```text
原始数据表必须放在正文
```

则服从教师要求。

否则默认：

> **原始数据放附录，正文只保留拟合相关参数、最终结果及必要分析。**

---

## 10.1 统计表类型

按实验需要选择，不机械全部生成。

### 原始测量数据表

保存真实数据。

### 重复测量统计表

| 测量量 | 平均值 | 标准差 | 极差 | A类不确定度 | 相对标准差 |
|---|---:|---:|---:|---:|---:|

### 直接量不确定度表

| 物理量 | 测量值 | A类 | B类 | 合成标准不确定度 | 相对不确定度 |
|---|---:|---:|---:|---:|---:|

### 不确定度贡献表

| 物理量 | 灵敏系数 | 标准不确定度 | 传播后贡献 | 贡献比例 |
|---|---:|---:|---:|---:|

### 拟合参数表

| 参数 | 拟合值 | 标准误 / 不确定度 | 单位 | 物理意义 |
|---|---:|---:|---|---|

### 残差表

| 数据点 | 实验值 | 拟合值 | 残差 | 相对残差 |
|---|---:|---:|---:|---:|

### 理论 / 实验对比表

| 项目 | 实验值 | 理论 / 参考值 | 绝对偏差 | 相对偏差 |
|---|---:|---:|---:|---:|

### 多条件对比表

| 条件 | 关键结果 | 不确定度 | 相对变化 | 备注 |
|---|---:|---:|---:|---|

### 误差类型与来源分析表

| 误差类型 | 具体来源 | 影响量 | 数据证据 | 传播机制 | 可能方向 | 可否定量 | 改进 |
|---|---|---|---|---|---|---|---|

用于区分：

```text
随机误差 / 系统误差 / 粗大误差（如适用）
```

以及对应的具体仪器、操作、环境或模型来源。

正式报告通常只需突出 1～2 个主要误差类型，其余次要因素可简述。

### 最终结果汇总表

用于多个最终物理量。

---

## 10.2 主要误差类型与对应图像

误差图像不是为了“每种误差配一张图”，而是为了给**最重要的 1～2 个误差判断提供证据**。

优先采用下列对应关系。

### A. 随机误差

适合图像：

- 重复测量散点图；
- 带均值线的重复测量图；
- 箱线图（重复次数足够时）；
- 直方图（样本数足够时）；
- 拟合残差图；
- 不确定度贡献条形图。

主要观察：

- 数据离散程度；
- 是否围绕均值随机波动；
- 是否存在明显偏态或异常点；
- 随机项是否为主要不确定度贡献。

### B. 系统误差

适合图像：

- 实验值与理论 / 参考值对比图；
- 带误差棒的结果对比图；
- 残差随自变量变化图；
- 正程 / 反程对比图；
- 不同仪器 / 不同方法结果对比图；
- 零点或基准偏移前后对比图；
- 参数随条件变化的趋势图。

主要观察：

- 是否整体位于参考值同一侧；
- 是否存在稳定方向的偏移；
- 残差是否呈趋势；
- 不同方法是否存在稳定差值；
- 校正后偏差是否明显减小。

### C. 粗大误差 / 异常失误

适合图像：

- 原始数据散点图；
- 残差图；
- 重复测量序列图；
- 必要时的箱线图。

主要用途：

- 定位明显异常点；
- 对照原始记录；
- 辅助判断是否需要重测。

粗大误差图像只能用于**发现和定位疑点**，不能单凭“看起来离群”自动删除数据。

### D. 不确定度主导来源

若重点讨论的是哪个测量量限制了最终精度，可使用：

- 不确定度贡献条形图；
- 横向条形图；
- 贡献比例图；
- 少量分量时可用饼图。

但要明确：

> “不确定度贡献图”描述的是各不确定度分量对最终不确定度的贡献，不等于直接证明某一项就是实际误差来源。

### E. 图像数量原则

正式报告中的误差相关图像通常优先控制在：

```text
1～2 张主要误差图
+
必要的主结果 / 拟合图
```

如果一个实验最重要的是随机误差，就优先把图像资源用于重复性或残差。

如果最重要的是系统误差，就优先展示偏移、趋势或方法对比。

如果两者都明显，可分别选一张最能说明问题的图。

不要为了覆盖所有误差类别而生成大量价值重复的图。

---

## 10.3 图表选择

原则：

> **图表类型必须匹配数据性质和物理问题，不为了“图多”而换图。**

可使用：

- 散点图；
- 拟合图；
- 残差图；
- 折线图；
- 条形图 / 柱状图；
- 横向条形图；
- 堆叠条形图；
- 百分比堆叠图；
- 扇形图 / 饼图；
- 误差棒图；
- 箱线图；
- 直方图；
- 理论值与实验值对比图；
- 不确定度贡献图。

---

## 10.4 常见图型适用条件

### 散点图

两个连续物理量关系、拟合、理论验证。

### 拟合图

必须包含实验数据点；可叠加拟合线、理论线、误差棒。

### 残差图

重要拟合且数据量足够时优先考虑。

### 折线图

时间序列或有序连续变化；不用于独立类别。

### 条形图

类别比较、误差贡献、不确定度贡献、方案对比。

### 堆叠条形图

比较多个条件下各组成分量。

### 扇形图 / 饼图

只用于“一个总量由少数可加分量组成”的比例，例如不确定度贡献比例。

类别较多或只想比较大小时，条形图优先。

### 箱线图

重复测量较多时展示分布与离散。

### 直方图

样本数足够时展示重复测量分布；少量数据不要强行使用。

### 误差棒图

只有有可靠不确定度依据时使用，并注明误差棒含义。

---

## 10.5 表格与图分工

```text
表格
→ 给精确数值

图像
→ 展示趋势、结构、分布、差异

正文
→ 解释物理意义
```

避免一张表和一张图完全重复同一信息而没有额外价值。

---

## 10.6 每张正式图必须回答一个问题

大纲阶段为每张图明确：

- 图名；
- 图型；
- 数据来源；
- x 轴；
- y 轴；
- 是否误差棒；
- 是否拟合；
- 是否理论线；
- 所属章节；
- 这张图要回答什么物理问题。

---

## 10.7 图表正文规则

每张重要图表必须：

```text
先引出
→ 展示
→ 指出主要趋势
→ 解释物理意义
→ 必要时讨论偏离或误差
```

禁止：

```text
实验结果如图3所示。
```

之后不分析。

---

## 10.8 图表视觉规则

- 不使用 3D；
- 不使用夸张渐变；
- 不使用纯装饰色彩；
- 不靠颜色单独编码，必要时结合点型、线型；
- 全篇视觉风格一致；
- 坐标轴必须有物理量和单位；
- 图例清楚；
- 字体可读；
- 文件名按物理内容命名，例如：
  - `摆长与周期平方关系图.pdf`
  - `线性拟合残差图.png`
  - `不确定度贡献图.png`

<a id="sec-11"></a>
# 11. 讲义高保真与实验内容高保真

## 11.1 总原则

凡正式报告中直接来源于实验讲义的内容，默认：

> **保真优先于改写。**

包括：

- 实验目的；
- 实验原理；
- 理论公式；
- 公式含义；
- 适用条件；
- 仪器说明；
- 实验内容；
- 操作步骤；
- 讲义注意事项；
- 思考题原始要求。

---

## 11.2 原文合适时尽量保持原样

如果讲义表述已经：

- 清楚；
- 准确；
- 篇幅合适；
- 适合报告；

则尽量：

- 保留术语；
- 保留原逻辑顺序；
- 保留关键句式；
- 保留公式前后解释；
- 保留关键条件；
- 只做格式、标点、LaTeX 和人称的轻微整理。

不得为了：

- 更学术；
- 更简洁；
- 更像论文；
- “去 AI 味”；

而主动大幅重写。

---

## 11.3 只有原文过长时才简化

压缩顺序：

```text
先删重复
↓
再删与当前实验无关的课堂提示
↓
再压缩过长操作说明
↓
最后才压缩物理解释
```

必须保留：

- 原术语；
- 原物理含义；
- 原公式关系；
- 原适用条件；
- 原逻辑顺序。

---

## 11.4 “实验内容”是高保真区域

讲义怎么划分任务，正式报告中的“实验内容”就尽量怎么写。

例如讲义为：

```text
1. 固定摆长测量重力加速度
2. 改变摆长研究 T² 与 L 的关系
3. 大摆角影响（选做）
```

如果用户只做 1、2：

```text
保留第1项
保留第2项
第3项不写
```

原则：

> **删掉没做的，不重写做过的。**

不得改写成抽象的论文式任务名称。

---

## 11.5 实验内容中的参数尽量保留

用户实际按讲义执行的：

- 范围；
- 步长；
- 重复次数；
- 累计周期数；
- 固定条件；
- 控制变量；
- 仪器量程；
- 作图变量；

尽量按讲义原方式保留。

例如讲义写：

```text
从 50.00 cm 开始，每次增加 5.00 cm，直至 80.00 cm。
```

若用户确实这样做，不要压缩成：

```text
在 0.50~0.80 m 范围内选取若干摆长。
```

---

## 11.6 “实验内容”和“实验方法和技术”区分

### 实验内容

回答：

- 做了哪些任务；
- 测了什么；
- 改变了什么条件；
- 验证了什么关系。

高保真复述讲义。

### 实验方法和技术

回答：

- 实际怎样测；
- 怎样读数；
- 怎样重复；
- 怎样减小偶然误差；
- 怎样拟合或处理。

可以根据用户真实操作适度组织语言。

---

<a id="sec-12"></a>
# 12. 第四步：正式报告结构、语言与写作

第四步在第三步总体文字大纲完成后执行。

---

## 12.1 严格映射教师模板

正式报告只能在已锁定的教师结构中填充内容。

正式报告中的数据表格同时读取章节状态文件中的“正式报告数据表格类型”：

```text
全框表格（默认）
三线表
```

如果教师模板已明确规定表格样式，则教师模板优先。

除非教师或课程明确要求原始数据必须出现在正文，否则正文默认只保留拟合参数、最终结果及必要分析，完整原始数据放在附录。

大纲、正文、图表、公式全部映射到教师指定章节。

课程只要求“数据处理与分析”的实验，不强行补：

- 引言；
- 完整实验方法；
- 实验小结；

除非课程明确要求。

---

## 12.2 大学生物理实验报告的总体语言风格

正式实验报告的目标风格为：

> **客观陈述 + 适度学术用语 + 数据支撑 + 误差分析 + 适量学生式反思。**

整体应体现大学生实验报告的自然表达：

- 比高中实验报告更规范；
- 比正式学术论文更自然；
- 不过度口语化；
- 不刻意写成论文摘要；
- 不为了“学术感”使用生硬复杂句；
- 不为了“学生味”故意加入错误、口头语或不规范表达。

典型语言风格：

```text
半正式
+
偏学术
+
叙述清楚
+
数据导向
+
语气克制
```

---

## 12.3 主语与句式习惯

正式报告可以自然使用：

```text
我们
本实验
本文
```

其中：

- “我们”可作为主要第一人称复数主语，用于描述实际操作、测量和数据处理；
- “本实验”适合说明实验目的、方法和结果；
- “本文”可以偶尔使用，但不宜像正式论文一样高频出现；
- 被动或无主句式也可以自然使用，例如“测量得到”“记录如下”“可计算得”。

推荐句式：

```text
我们采用……方法测量了……
本实验通过……验证了……
由公式（3）可计算得到……
将数据代入后得到……
根据表2中的数据可知……
与理论值相比，相对偏差为……
```

不要机械要求每段都以“本实验”开头，也不要完全回避第一人称。

---

## 12.4 语气要求：客观、克制、不过度夸张

避免：

```text
结果非常完美
误差大得离谱
实验效果特别好
完全证明了……
```

优先写：

```text
实验结果与理论值基本吻合
结果与参考值较为接近
偏差处于可接受范围内
偏差较大，需要进一步分析
数据呈现出较明显的线性关系
```

评价必须与真实数据相符。

---

## 12.5 常用实验词汇

根据实验内容自然使用：

```text
测量
记录
计算
推导
验证
拟合
校准
调节
读数
估读
重复测量
控制变量
平均值
标准差
不确定度
相对偏差
绝对偏差
线性拟合
斜率
截距
残差
有效数字
异常数据
```

术语优先服从课程讲义。

如果课程明确使用“偶然误差”“随机误差”“相对误差”等术语，则按照课程材料使用。

---

## 12.6 连接词与逻辑词

可以自然使用：

```text
首先
其次
然后
最后
由……可知
根据……可得
由此可以看出
然而
但值得注意的是
相比之下
因此
从而
综上
```

这些词不需要刻意回避。

但不要机械连续使用：

```text
首先……
其次……
然后……
最后……
综上所述……
```

连接词的作用是帮助逻辑衔接，不是形成固定模板。

---

## 12.7 数据表达习惯

数据表达遵循：

- 保留与测量精度和不确定度相符的有效数字；
- 不无依据多写小数位；
- 表格有明确表题；
- 图有明确图题；
- 关键数据前后有文字说明；
- 关键计算给公式和必要代入；
- 普通重复计算不需要全部逐项展开。

推荐结构：

```text
引出数据
→ 表格 / 图像
→ 指出主要趋势
→ 给出关键计算或拟合
→ 解释物理意义
```

例如：

```text
由表1可知，随着电压增加，电流整体呈近似线性增长。
以 I 为纵坐标、U 为横坐标进行线性拟合，得到斜率 k=……，截距 b=……。
结合拟合结果可进一步得到……
```

不要把正文写成纯公式堆叠或程序输出。

---

## 12.8 实验目的的语言习惯

实验目的常使用：

```text
掌握
了解
验证
测定
研究
熟悉
学习
```

一般保持简洁。

如果讲义已经给出实验目的，则优先遵循第 11 节“讲义高保真”规则，不为了风格统一而大幅改写。

---

## 12.9 实验原理的语言习惯

原理部分应：

- 说明物理模型；
- 给出核心公式；
- 说明公式中的物理量；
- 交代适用条件；
- 说明公式在本实验中的用途。

推荐逻辑：

```text
物理关系
→ 公式
→ 变量定义
→ 适用条件
→ 本实验如何利用该关系
```

不要写成：

```text
公式推出来就是这样的。
```

也不要为了显得正式而写成过度复杂的论文式表述。

---

## 12.10 实验步骤的语言习惯

实验步骤按实际操作顺序写，常用：

```text
连接
调节
校准
记录
读取
重复
改变
保持
测量
```

要求：

- 清楚；
- 简洁；
- 保留关键条件；
- 不写成冗长说明书；
- 不删除影响结果的重要操作。

如果讲义步骤已经清楚，则继续遵守高保真原则。

---

## 12.11 数据记录与处理的语言习惯

正式报告正文的数据处理部分默认不放完整原始数据表。

正文应重点包含：

- 关键公式；
- 必要计算示例；
- 拟合模型；
- 拟合参数；
- 拟合参数的不确定度 / 标准误（如适用）；
- `R²`、残差等必要拟合信息；
- 由拟合得到的最终物理量；
- 最终不确定度或相对偏差；
- 对结果的简要解释。

完整原始测量数据统一放入附录，并在正文中通过“见附录表……”等方式引用。

不要把所有计算过程完全展开，也不要只给最终答案。

重要结果优先按：

```text
数据依据
→ 计算方法
→ 数值结果
→ 物理解释
```

展开。

---

## 12.12 误差分析的语言习惯

正式报告中的误差分析应遵循：

> **先定量，再定性；先判断误差类型，再追查具体来源；重点分析 1～2 个主要误差，不平均罗列所有可能因素。**

写作时优先区分：

```text
随机误差
系统误差
粗大误差 / 异常失误（如确有证据）
```

然后再说明对应来源，例如：

```text
仪器
操作
环境
测量方法
理论模型
数据处理
```

推荐结构：

```text
本次数据最明显的误差特征是什么
→ 属于随机还是系统性影响
→ 主要来源是什么
→ 数据或图像有什么证据
→ 如何传播到最终结果
→ 怎样改进
```

例如随机误差可以写：

```text
重复测量结果在平均值附近存在一定离散，且各次偏差没有明显固定方向，
说明当前结果中的主要波动具有随机性。
结合 A 类不确定度可见，……是主要随机波动来源。
图X中的重复测量散点也显示各点主要围绕均值上下分布。
```

例如系统误差可以写：

```text
多组实验结果整体位于参考值同一侧，且残差随……呈现较一致的偏移，
说明结果可能存在系统性影响。
结合实验装置，……的基准位置偏差会直接影响……，
并通过……关系使最终结果产生同方向偏移。
```

如果两类误差都重要，可以分别用一段分析：

```text
第一段：主要随机误差
第二段：主要系统误差
```

不要求再把所有次要误差逐项展开。

误差图像也应服务于主要误差：

- 随机误差 → 重复测量散点、箱线图、残差图；
- 系统误差 → 实验/参考对比、残差趋势、正反程或方法对比；
- 粗大误差 → 原始数据散点或残差图辅助定位；
- 不确定度主导量 → 不确定度贡献条形图。

正式报告中常见的“仪器误差、人为误差、环境误差、方法误差”可以作为**来源层面的组织方式**，但不要把它们与“随机误差、系统误差”混为同一级误差类型。

## 12.12.1 正式报告不写内部检查阈值

以下内容属于工作流内部判断：

```text
本章自定义快速筛查阈值
δ_screen
通过 / 未通过筛查
用户确认门
```

除非课程或用户明确要求，否则不进入正式实验报告。

正式正文只保留实验本身有意义的结果与分析：

```text
实验结果
理论值 / 参考值
相对偏差
不确定度
主要误差来源
物理解释
```

如果因为未找到仪器精度数据，并经用户允许按仪器误差为零处理，则正式报告可直接写：

```text
由于未找到该仪器的精度数据，本次计算中认为该仪器误差为零。
```

或：

```text
由于未查到可用于误差评定的仪器精度参数，本次计算中暂按该仪器误差为零处理。
```

不要写：

```text
为了通过内部筛查阈值……
按照筛查规则……
低于筛查阈值，因此结果合格……
```

---

## 12.13 实验结论的语言习惯

结论应简洁回答：

```text
测得什么
→ 与理论 / 参考结果关系如何
→ 验证或研究了什么规律
→ 主要精度或偏差怎样
```

不重复整张数据表。

可以使用：

```text
通过……测得……
与理论值相比……
结果表明……
在本次测量范围内……
```

不要写：

```text
完美验证
完全证明
具有重大意义
```

---

## 12.14 学生式反思

允许在课程要求的“体会或收获”“实验小结”“思考与讨论”等位置写少量学生式反思。

可以写：

```text
通过本次实验，我们进一步理解了……
在数据处理过程中，可以看出……
今后的测量中应更加注意……
若进一步改进，可……
```

但必须遵守：

> **不编造用户没有提供的具体实验经历、故障、困难或情绪。**

如果用户没有提供真实操作感受，可以写方法层面的认识，例如：

```text
从不确定度贡献可以看出，提高长度测量精度比继续增加计时次数更有效。
```

不要虚构：

```text
我们调试了很久才成功
我们深刻体会到……
本次实验让我受益匪浅……
```

除非用户真实提供了这些经历。

---

## 12.15 遇到实验问题时的表达

如果存在真实记录的问题，可以诚实说明：

```text
由于……，该组数据波动较大。
由于实验时间限制，未继续增加测量组数。
该点与整体趋势偏离较大，结合原始记录判断可能与……有关。
```

如果数据被排除，必须有明确依据，并说明排除原因。

不得为了让报告更像“学生写的”而主动制造：

- 异常数据；
- 未做实验；
- 仪器故障；
- 时间不足；
- 操作失误。

---

## 12.16 正式报告内容结构仍以教师模板为准

典型学生实验报告常见：

```text
实验名称
实验目的
实验原理
实验仪器与器材
实验步骤
数据记录与处理
误差分析
实验结论
思考与讨论
```

但这只是语言风格参考，**不是新的统一结构模板**。

如果教师正式模板采用其他结构，例如：

```text
引言
实验内容与数据处理
实验小结
```

则必须完全保留教师结构，只把上述写作风格映射到相应章节中。

不得因为本风格指南列出了“典型结构”，就擅自改写教师模板。

---

## 12.17 不写 AI 自我免责声明和内部工作流语言

除非课程明确要求披露工具使用，否则正式报告中不出现：

```text
AI
Codex
大语言模型
自动生成
模型生成
本报告仅供参考
本报告不构成……
需要人工复核……
```

Python、Excel、MATLAB、Origin 等若确实用于数据处理，可以正常写：

```text
采用 Python 对数据进行线性拟合。
```

不要写：

```text
本报告由 Codex 调用 Python 自动生成。
```

---

## 12.18 不追求极限精炼，也不注水

实验报告不能写成技术摘要。

重要分析按：

```text
依据
→ 现象 / 数据
→ 判断
→ 结论
```

说完整。

允许展开：

- 物理过程；
- 数据趋势；
- 方法理由；
- 理论关系；
- 不确定度来源；
- 误差机制；
- 图表含义；
- 学生式方法反思。

禁止通过以下方式增加篇幅：

- 重复结论；
- 空泛背景；
- 套话；
- 无依据主观感受；
- 与实验无关的知识扩写。

---

## 12.18.1 标题与正文必须分行

正式报告中，凡承担“标题、分项标题、小标题、加粗提示标题”作用的文字，标题结束后必须换行，再开始正文。

尤其是使用 Markdown / LaTeX 粗体模拟小标题时，不要把正文直接接在同一行。

推荐：

```markdown
**误差分析**

从重复测量结果可以看出……
```

```markdown
**随机误差**

多次测量值主要围绕平均值上下波动……
```

不推荐：

```markdown
**误差分析** 从重复测量结果可以看出……
```

```markdown
**随机误差：**多次测量值主要围绕平均值上下波动……
```

适用于：

- Markdown 粗体小标题；
- LaTeX 中用 `\textbf{}` 形成的小标题；
- 误差分析中的“随机误差”“系统误差”等分类标题；
- “实验结果”“数据处理”“改进方法”等正文内部提示标题；
- 列表中实际承担段落标题作用的加粗文字。

LaTeX 推荐：

```latex
\textbf{随机误差}

多次测量结果在平均值附近存在一定离散……
```

不要写成：

```latex
\textbf{随机误差} 多次测量结果在平均值附近存在一定离散……
```

如果粗体文字只是句子中的普通强调，而不是标题，则不强制换行。

例如：

```markdown
本实验中，**长度测量**是不确定度的主要贡献项。
```

判断标准：

> **只要粗体文字承担“标题”作用，就必须单独成行；只要只是句内强调，就继续留在正文中。**

## 12.19 图、表、公式与正文的衔接

### 公式

```text
说明为什么需要
→ 给出公式
→ 解释符号
→ 说明本实验如何使用
```

### 表格

```text

→ 表格
→ 描述主要数据特征
```

### 图像

```text

→ 图像
→ 描述趋势
→ 解释物理意义
```

不要写：

```text
结果如图3所示。
```

然后不再解释。

## 12.20 正文生成与润色流程

第四步内部统一采用：

### A. 技术内容确认

确认：

- 讲义内容；
- 实际测量；
- 数据结果；
- 不确定度；
- 图表；
- 误差分析；
- 思考题；
- 结论。

### B. 按第三步大纲生成完整正文

每个自然段对应已确认的大纲主题，不重新设计正式报告结构。

### C. 文风润色

逐段检查：

- 是否符合“半正式、偏学术、不过度论文腔”；
- 是否自然使用“我们 / 本实验 / 被动句式”；
- 是否存在太口语化表达；
- 是否存在过度复杂的论文式表达；
- 是否出现连续机械连接词；
- 是否存在“粗体标题后直接接正文”的排版；标题性粗体必须换行后再写正文；
- 数据是否有文字说明；
- 误差分析是否先定量后定性；
- 结论是否简洁；
- 学生式反思是否真实；
- 是否出现夸张表述；
- 是否出现 AI 自我免责声明；
- 是否把讲义高保真部分过度改写；
- 是否存在程序日志或内部工作流语言；
- 是否出现无依据的“完美吻合”“高精度”等判断。

# 13. 仪器参数缺失时的联网补全

## 13.1 触发条件

第二步发现正式分析或“检查数据”需要的仪器参数缺失时，例如：

- 分辨率；
- 分度值；
- 准确度；
- 最大允许误差；
- 准确度等级；
- 量程相关误差；
- 零点修正；
- 标定修正；
- 传感器精度；

进入本节流程。

不得直接猜测，也不得自动认为仪器无误差。

## 13.2 先说明缺失并请求联网授权

输出：

```text
仪器：
当前可确认型号 / 标识：
缺失参数：
为什么需要：
影响的计算：
```

然后询问用户是否允许联网查找官方说明书、技术手册或可靠技术资料。

只有用户明确批准后才能联网。

## 13.3 联网来源优先级

批准后优先：

1. 厂家官网；
2. 官方说明书；
3. 官方技术手册 / datasheet；
4. 学校实验中心或课程官方资料；
5. 官方技术规格 PDF；
6. 正规经销商发布的厂家规格页。

避免优先采用无来源论坛、个人博客、电商评论、无法确认型号的转载。

## 13.4 型号匹配规则

优先利用：

- 仪器铭牌；
- 品牌和型号；
- 量程 / 档位；
- 用户照片；
- 讲义装置图；
- 实验室设备编号。

不得把网上任意一款同类仪器参数直接当成本次仪器参数。

## 13.5 何时可自动采用，何时需要再次询问

用户已经授权联网后：

```text
具体型号明确
+
找到唯一匹配的官方资料
+
量程 / 档位匹配
+
参数定义清楚
→ 自动采用
→ 记录来源
→ 不再二次打断用户
```

只有出现以下情况才再次询问：

- 型号不能唯一确认；
- 多个官方来源参数冲突；
- 同型号不同量程 / 版本无法确定；
- 参数定义或适用条件不清楚；
- 只能找到低可信度来源。

## 13.6 不修改原始 Excel

用户填写后的原始 Excel 是原始证据，保持只读。

联网补充的仪器参数不得写回用户原始实测 Excel。

按当前阶段处理：

```text
第二步 / “检查数据”阶段
→ 先写入章节状态文件
→ 如当前检查确需表格承载，可写入临时分析副本
→ 不提前生成正式 05_数据处理结果文件

第三步
→ Python 正式分析时
→ 将已确认仪器参数写入 05_数据处理结果_[实验名称].xlsx
```

这样既保护原始数据，也避免在第三步之前提前生成正式结果文件。

建议字段：

| 仪器 | 型号 | 参数名称 | 参数值 | 单位 | 来源 | 用途 |
|---|---|---|---:|---|---|---|

并同步写入章节状态文件。

## 13.7 多仪器记录

章节状态文件按仪器分别记录：

```markdown
## 六、联网补充仪器参数

### 仪器：{{名称}}
品牌：
型号：
量程 / 档位：
参数：
来源：
来源链接：
查询日期：
用户是否批准联网：
采用方式：自动采用 / 用户确认
用于哪些计算：
是否查找失败：
是否经用户允许按仪器误差为 0：
对结果可能造成的影响：
```

有多台仪器时重复 `### 仪器：...` 子节。

## 13.8 补齐参数后的计算边界

仪器关键精度参数补齐后，先检查当前实验的筛查阈值是否仍合理。

执行：

```text
读取当前已确认筛查阈值
→ 根据明确仪器精度重新估计正常可接受波动
→ 给出“仪器精度明确后的更具体推荐值”
```

如果新旧推荐基本一致：

```text
不打断用户
→ 保留现有阈值
→ 状态标记为“已由仪器参数复核”
```

如果差异明显：

```text
向用户说明：
原确认阈值：
新推荐阈值：
变化原因：
→ 等待用户确认是否更新
```

只有用户确认后才能修改章节状态中的最终阈值。

如果当前仍在第二步或“检查数据”阶段：

```text
只重算当前检查所需的简化结果
+
U_instr 或其他快速筛查所需量
+
δ_screen（如适用）
```

不得在此提前完成第三步的：

- 正式 B 类不确定度汇总；
- 正式合成不确定度；
- 全量传播；
- 不确定度贡献分析；
- 正式图表。

进入第三步后，Python 再读取已确认仪器参数，完成全部正式计算。

## 13.9 确实找不到可靠参数

只有同时满足：

1. 课程资料、原始记录均没有；
2. 用户已批准联网；
3. 已查找可靠来源；
4. 仍无法确认可信参数；

才再次询问用户是否允许：

> **本次计算中暂按该仪器误差为 0 处理。**

只有用户明确同意后才可采用。

正式报告如需说明，可写：

```text
由于未找到该仪器的精度数据，本次计算中认为该仪器误差为零。
```

或：

```text
由于未查到可用于误差评定的仪器精度参数，本次计算中暂按该仪器误差为零处理。
```

状态文件必须注明这是计算假设，可能低估总不确定度。

## 13.10 与“检查数据”的衔接

参数缺失时：

```text
暂停当前快速筛查
→ 完成本节参数补全
→ 计算检查阶段需要的 U_instr
→ 使用本章已确认的 δ_threshold
→ 完成内部筛查
```

正式报告中不写内部筛查阈值或用户确认流程。

<a id="sec-16"></a>
# 16. 用户指令触发规则

## 16.1 读取总规则但未指定大章

用户只发送：

```text
读取总规则
读取规则
```

且没有指定实验大章时：

- 读取本规则；
- 不创建章节状态文件；
- 不执行完整第零步；
- 提示用户使用类似：
  `根据总规则，开始[实验大章名称]`。

## 16.2 “根据总规则，开始[大章]”

用户明确指定实验大章后，执行完整第零步：

```text
识别大章
→ 提取 / 整理本章资料
→ 阅读并理解本章全部实验
→ 建立初步任务判定
→ 基于本章推荐检查数据筛查阈值
→ 输出用户信息与个性化设置
→ 等待用户确认 / 修改
→ 用户确认后按第 0.6 节生成并输出完整章节状态文件
→ 默认停止，等待进入第一步
```

如果用户明确说“确认并继续第一步”，则按第 0.6 节先输出章节 Markdown，再继续第一步。

## 16.3 第二步

用户说明真实原始数据已填写并要求处理时，执行第二步。

第二步只做完整性、记录精度、仪器参数状态、物理合理性和异常检查。

## 16.4 “检查数据”

用户明确发送：

```text
检查数据
```

时：

- 读取章节状态中的 `δ_threshold`；
- 使用第二步仪器参数核对结果；
- 缺参数时按第13节处理；
- 执行内部快速筛查；
- 完成后等待用户明确确认。

## 16.5 第三步

第二步通过后可以进入第三步；如果用户曾触发“检查数据”，则必须先取得该次检查后的用户确认。

## 16.6 第四步

第三步正式分析和总体文字大纲完成后，用户要求继续时执行第四步。

## 16.7 继续任务

跨对话或中断后继续时：

```text
总规则
→ 个人信息
→ 章节状态
→ 本章已确认个性化设置
→ 本章资料
→ 当前阶段所需数据
```

从状态中的“下一步”继续，不重复生成已经验收通过的成果。

# 最终核心原则

整套流程最终只保留一条主线：

```text
第零步：先把实验大章理解、用户信息和个性化设置确认对
第一步：再把实验准备对
第二步：再把真实数据检查对
第三步：再把数据分析对、报告逻辑规划对
第四步：最后把正式报告写对、编译对、交付对
```

并始终遵守：

> **讲义内容尽量保真，真实数据绝不美化，误差分析必须有物理依据，图表必须服务于分析，正式报告只写用户真正做过的实验内容。**
