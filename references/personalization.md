# 实验报告个性化建议

这些选项在用户需要时提出，可直接沿用已有偏好。教师要求优先，科学依据决定数值与结论。用户没有选择的建议保持为可选项。

| 选项 | 可以怎样设置 | 建议确认时机 |
|---|---|---|
| 默认任务范围 | 本章实际参与、完整报告、合并报告、数据处理、观察记录 | 新章节或任务改变 |
| 准备深度 | 完整预习稿、操作要点与记录表、复用课程表 | 实验前 |
| 配合方式 | 配置后暂停、按阶段交付、资料齐全后连续完成 | 首次使用，后续继承 |
| 正文详略 | 按教师页数与评分点，推导展开程度，图表解释篇幅 | 首份报告 |
| 分析侧重点 | 不确定度贡献、模型适用范围、操作改进或条件对比 | 已有可靠分析结果 |
| 公式呈现 | 关键推导展开、常规代入简写、符号首次定义方式 | 首份报告 |
| 图表样式 | 三线或全框，配色、误差棒、拟合与残差组合 | 首份报告 |
| 原始数据组织 | 按教师要求安排正文与附录，重复测量明细与摘要对照 | 锁定模板时 |
| 修改范围 | 仅润色、数值核查、方法复核或整体更新 | 修改已有报告时 |
| 真实反思 | 用户提供的现场问题、改进体会及其报告位置 | 成稿前有素材时 |
| 复现交付 | 分析程序、输入映射、依赖与运行说明的展示程度 | 正式分析时 |

可建议用户先选“任务范围、配合方式、正文详略”三项，其余继承当前设置。记录设置值、适用范围、来源和确认日期。实验专属设置覆盖章节默认，章节默认覆盖通用偏好，明确的教师要求覆盖呈现偏好。

参考表达“这一章 A 独立写，B/C 合并，D 只记录观察。准备时用操作要点和记录表，数据齐全后连续完成。正文重点解释模型与误差机制，保持现有文风和教师标题”。

正文语气可选择直接陈述、适度审慎或讨论展开，默认直接陈述。无论选择哪一种，结论强度由证据决定。用户可指定“保留必要方法限制，删去重复提醒与写作辩解”，并记录为章节或跨章节偏好。
