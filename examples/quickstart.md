# Quick Start｜完整最小使用示例

## 1. 启动大章

用户：

```text
根据总规则，开始力学实验
```

Skill：

```text
读取个人信息
→ 读取课程要求
→ 定位“力学实验”
→ 提取 / 整理该章资料
→ 阅读本章统一要求和全部实验
→ 建立初步任务判定
```

然后输出类似：

```text
【第零步：本章信息与设置确认】

大章：力学实验
本章包含实验：……
报告要求：……

Excel 原始输入：淡黄色
Excel 固定参数：浅灰
Excel 现场计算：淡蓝
Excel 表格边框：全框

正式报告数据表格：全框表格
正式报告原始数据：附录

检查数据筛查阈值（初始推荐）：2.0%
筛查阈值状态：初始推荐
推荐依据：
- 当前实验属于普通定量测量
- 理论参考值可靠
- 普通本科实验室存在一定人工读数和操作波动

请确认或修改。
```

## 2. 用户确认

用户：

```text
正式报告改成三线表，其他按推荐。
```

Skill 更新设置并等待最终确认。

用户：

```text
确认
```

Skill 生成并输出：

```text
第XX章_力学实验/
└─ 00_章节状态_力学实验.md
```

然后默认暂停。

## 3. 第一步

用户：

```text
执行第一步
```

Skill 为所有实际要做的实验生成：

```text
01_预习报告_[实验名称].tex
02_预习报告_[实验名称].pdf
03_实验数据填写表_[实验名称].xlsx
```

## 4. 第二步

实验后：

```text
“利用单摆测重力加速度”的真实原始 Excel 已填写，执行第二步。
```

Skill 检查完整性、单位、精度、重复次数、物理合理性、异常点和仪器参数。

若缺仪器参数：

```text
缺少：秒表准确度
影响：B 类不确定度和内部检查
是否允许联网查找官方说明书？
```

用户：

```text
允许
```

若型号和官方参数唯一匹配，Skill 自动采用并写入章节状态，不修改原始 Excel。

随后复核筛查阈值。若差异明显：

```text
原确认阈值：2.0%
新推荐阈值：1.5%
变化原因：……
是否更新？
```

## 5. 可选“检查数据”

用户：

```text
检查数据
```

Skill 使用最终确认阈值进行内部快速筛查，完成后等待确认。

用户：

```text
确认，可以继续。
```

## 6. 第三步

用户：

```text
执行第三步
```

Skill 生成并运行：

```text
04_数据处理程序_[实验名称].py
```

并输出：

```text
05_数据处理结果_[实验名称].xlsx
06_实验图像_[实验名称]/
```

完成正式不确定度、拟合、残差、误差分析、统计表、正式图像和报告总体大纲，但不直接写最终正文。

## 7. 第四步

用户：

```text
执行第四步
```

Skill：

```text
按教师模板生成正式正文
→ 完整原始数据放附录
→ 正文保留拟合参数、最终结果和分析
→ 编译 PDF
→ 检查数值和版式
→ 清理临时文件
→ 最终交付
```
